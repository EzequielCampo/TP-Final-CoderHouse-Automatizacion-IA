# 🤖 Sistema Inteligente de Gestión de Casos Técnicos mediante IA

## Trabajo Final – Automatización con IA – CoderHouse

### Autor
**Ezequiel Campo**

---

## Descripción

Este proyecto implementa un ecosistema de automatización para un servicio técnico de reparación de celulares utilizando Inteligencia Artificial.

El sistema recibe consultas de clientes, analiza automáticamente el problema mediante Google Gemini, registra la información en Airtable y genera una respuesta técnica sugerida para revisión del operador.

---

## Tecnologías utilizadas

- n8n
- Google Gemini
- Airtable
- Webhooks
- JSON
